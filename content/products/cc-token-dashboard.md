> **TL;DR**：同時開好幾個 Claude Code 工作時，常搞不清楚每個專案用掉多少 token。這個工具常駐選單列，點開就能看到各專案明細和圖表。

## 核心功能

- 常駐 macOS 選單列
- 各專案即時 token 折線與 KPI
- 本日產出、占比與明細表
